# OHMLUZ - Sitio Web Oficial

Repositorio del sitio web profesional de **OHMLUZ**, empresa especializada en servicios eléctricos, ingeniería, domótica, sistemas solares, redes y seguridad en Bogotá, Colombia.

## 🚀 Tecnologías utilizadas
* HTML5 / CSS3 Moderno (Diseño Responsivo)
* FontAwesome (Iconos)
* Integración directa con WhatsApp Business (`+57 3103160502`)

## 🛠️ Estructura del Proyecto
```text
ohmluz_web/
│
├── index.html       # Página principal
├── css/
│   └── style.css    # Estilos profesionales adaptados a la marca
├── js/
│   └── main.js      # Scripts interactivos (opcional)
└── img/             # Recursos gráficos y logotipos
```

## 🌐 Publicación / Despliegue
Este repositorio está listo para ser alojado en plataformas gratuitas o de bajo costo como **GitHub Pages, Vercel, Netlify o cualquier hosting tradicional**.
